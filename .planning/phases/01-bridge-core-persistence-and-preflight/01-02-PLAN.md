<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| bridge -> OpenSpec/GSD/Git subprocesses | Tool paths, versions, exit status, stdout bytes, stderr, and cwd cross an external process boundary. |
| verified working bytes -> source commit blobs | Git object data must match the already-read canonical artifact before persistence. |
| explicit Phase 2 inputs -> bridge preflight | Approval, repository policy, and visible host verdict are trusted only after typed validation, never inferred. |
| manifest value -> repository filesystem | Existing state, staging bytes, replacement, and cleanup can fail independently. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-05 | Elevation / Tampering | `preflight.py` subprocess boundary | mitigate | Use fixed argv, explicit cwd/timeout, `shell=False`, injected runner tests, and exact pinned parsers. |
| T-01-06 | Tampering / Repudiation | Git source parity | mitigate | Read `source_commit:path` blobs and compare exact bytes/hash to Plan 01 artifacts before write authorization. |
| T-01-07 | Spoofing / Elevation | host capability input | mitigate | Require a typed explicit inspected verdict and reject absent/unknown values; never derive it from GSD signals. |
| T-01-08 | Tampering | `manifest.py` state guard | mitigate | Validate existing/next state, stage in target directory, reparse closed bytes, and replace only after all read-only gates pass. |
| T-01-09 | Denial of Service | subprocess and filesystem operations | mitigate | Bound subprocess time/output parsing via injected command result limits and reuse Phase 1 input limits; return classified failures. |
| T-01-SC | Tampering | package installs | accept | No dependency or install task exists in this plan; repository-pinned stdlib and existing dev tools only. |
</threat_model>
