## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| persisted source state → allocator | Malformed IDs, parents, counters, and tombstones can spoof prior identity. |
| observations + explicit matches → reconciled state | Ambiguous mapping can silently attach evidence to the wrong canonical source item. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-04 | Spoofing | namespaced source IDs | mitigate | Exact ASCII prefix/suffix validation, active/tombstone global uniqueness, and category/parent consistency. |
| T-01-05 | Tampering | explicit source reconciliation | mitigate | One-to-one explicit match validation, deterministic ordering, collision reporting, and no heuristic repair. |
| T-01-06 | Denial of Service | allocator bounds | mitigate | 4096 item cap, bounded Hypothesis strategies, integer counter limit, and sentinel refusal. |
| T-01-SC | Tampering | package supply chain | accept | No install or dependency change is required. |
</threat_model>
