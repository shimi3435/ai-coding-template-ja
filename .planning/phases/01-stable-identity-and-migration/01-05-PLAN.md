<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| reviewed preview + approval → mutation | Stale approval or target swap can apply bytes different from those reviewed. |
| staging file → target replacement | Partial write, validation gap, replace failure, or cleanup failure can corrupt or obscure target state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-13 | Tampering | approval/target freshness guard | mitigate | Literal approval, exact preview identity, immediate bounded target reread, and old-hash equality before staging. |
| T-01-14 | Tampering | staged persistence | mitigate | Same-directory staging, exact candidate bytes, bounded reread, strict schema-2 parse/value comparison, then one `os.replace`. |
| T-01-15 | Repudiation | migration failure evidence | mitigate | Separate failure point, target state, staging state, cleanup outcome, and post-replace reread evidence. |
| T-01-16 | Elevation of Privilege | migration target path | mitigate | Existing static manifest-tail, symlink, and repository-containment guards before mutation. |
| T-01-SC | Tampering | package supply chain | accept | No dependency install or package-manager mutation. |
</threat_model>
