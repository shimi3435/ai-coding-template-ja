## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI arguments / environment -> smoke | Repository, change ID, and GSD root select local files and commands. |
| OpenSpec/GSD/Git process output -> parsers | Tool output, exit codes, paths, counts, and JSON are untrusted evidence. |
| All repository entries except `.git` -> before/after fingerprint | Ignored files, large files, symlinks, empty directories, metadata changes, and concurrent writes must not be hidden by an otherwise successful capability result. |
| Internal evidence -> stdout/stderr | Absolute local paths, secrets, and canonical Markdown bodies must not cross the reporting boundary. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing / Tampering | real tool capability | mitigate | Require exact OpenSpec/GSD versions and existing Phase 1 full schema/file/root/agent signals; OpenSpec fallback is not a real-contract success. |
| T-03-02 | Elevation of Privilege | command dispatch | mitigate | Fixed argv, `shell=False`, explicit read-only allowlist, injected runner tests, and no mutable-operation imports or flags. |
| T-03-03 | Tampering / Repudiation | repository mutation verdict | mitigate | No-follow sorted traversal hashes every non-`.git` entry, streams all regular bytes, hashes symlink targets/modes/types, checks scan stability, and lets mismatch override success. |
| T-03-04 | Information Disclosure | JSON/human output | mitigate | Emit repository-relative identities/hashes only, redact `${GSD_HOME}`, omit raw probe JSON and canonical content, and test output for temp/home paths. |
| T-03-05 | Denial of Service | command output and fingerprint reads | mitigate | Reuse bounded command output; independently bound snapshot entry/path metadata/deadline while streaming every file without canonical-artifact byte ceilings and emitting constant-size digest/count output. |
| T-03-06 | Spoofing | no-GSD normal-check claim | mitigate | Run an actual nested task check under `env -i`, temporary config roots, curated PATH, and negative node/OpenSpec/GSD availability assertions. |
| T-03-SC | Tampering | package installs | accept | No package/dependency installation occurs; stdlib and repository-pinned tools only. |
</threat_model>
