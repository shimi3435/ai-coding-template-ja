<interfaces>
`serialize_manifest_refresh_preview(preview) -> Result[bytes]` is the public machine-view serializer. Its existing failure taxonomy is `Failure(ClassifiedIssue(IssueCategory.PERSISTENCE, "refresh-preview-invalid", KnownState.UNKNOWN))`. `_preview_identity(preview) -> str | None` is the apply state guard helper; `None` maps through public `apply_manifest_refresh` to `ManifestRefreshFailure` with `refresh-preview-invalid`, `RefreshFailurePoint.STATE_GUARD`, `RefreshTargetState.UNKNOWN`, `RefreshStagingState.ABSENT`, and `RefreshCleanupOutcome.NOT_NEEDED` before mutation.

`validate_source_identity_state(value) -> Result[SourceIdentityState]` is the sole canonical source-state validator. `_validate_source_state` uses `_SourceInputError(code)` for stable specific failures. The public wrapper must preserve that code first, then normalize any other ordinary `Exception` to INPUT / `source-state-invalid`; it must not catch `BaseException`.

`reconcile_source_items` returns the validator Failure unchanged. `build_manifest_mappings` and `validate_mapping_readiness` intentionally collapse validator Failure to `mapping-input-invalid`. `classify_canonical_source_drift` treats a validator Failure as incomplete canonical observation, and `gate_lifecycle_operation` exposes the same `canonical-observation-incomplete` wholly-unknown decision with no identity, paths, source IDs, progress, or remediation.
