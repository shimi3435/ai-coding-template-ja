It validates the supplied `ManifestMigrationPreview` through `_preview_identity` before target resolution or mutation and maps a `None` identity to the existing `ManifestMigrationFailure` with code `migration-preview-invalid`, failure point `STATE_GUARD`, target state `UNKNOWN`, staging state `ABSENT`, and cleanup `NOT_NEEDED`.

`_preview_identity` promises to return one validated identity without leaking input exceptions. Its current exception tuple encloses `_preview_is_consistent` and `_preview_machine_view`, but `_preview_has_valid_shape` executes before that boundary. Because Plan 03-27 intentionally admits supported `SourceIdentityState` subclasses through `validate_source_identity_state`, an overridden member getter can raise an ordinary `RuntimeError` during shape validation and escape public apply.

Keep the supported-subclass contract. Move the exact preview outer check, `_preview_has_valid_shape`, `_preview_is_consistent`, and `_preview_machine_view` into one `try`, and normalize `Exception` to `None`. Catch `Exception`, not `BaseException`: `KeyboardInterrupt`, `SystemExit`, and `GeneratorExit` remain process-control signals rather than malformed-input results. Do not move the exception policy into `source_identity.py`, add a second validator, or change public taxonomy.
