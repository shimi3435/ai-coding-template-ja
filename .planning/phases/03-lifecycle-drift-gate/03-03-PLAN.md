## Trust Boundaries

| Boundary | Description |
|---|---|
| canonical/tracked bytes → evidence producer | Repository inputs are security-relevant and evidence generation must neither substitute nor mutate them. |
| public lifecycle decision → tracked evidence | A serializer could omit blocking fields, relabel unknown as clean, or produce non-repeatable reviewer output. |
| prior identity → post-observation decision | A previously clean identity may be replayed after an admission-relevant observation changes. |
| optional external tools → normal CI/evidence claims | Tool availability and outputs are environment-dependent and must not become an implicit green prerequisite or unverified lifecycle proof. |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-10 | Spoofing/Tampering | high | canonical/tracked bytes → evidence producer | mitigate | Pin change/source identity and input digests, compare canonical and handoff bytes before/after, record zero mutations, and fail on any mismatch or staging residue. |
| T-03-11 | Tampering/Repudiation | high | public decision → JSON evidence | mitigate | Serialize only fixed typed fields with version tags and deterministic ordering, compare against independent literals and a second producer run, and retain unknown/drift issue codes without partial-green projection. |
| T-03-12 | Tampering/Elevation of Privilege | high | stale prior identity → admission | mitigate | Obtain both decisions from the public gate, change one complete bound input after the first observation, present the prior identity, and require stable stale rejection with `admitted=false`. |
| T-03-13 | Denial of Service | medium | evidence inputs | mitigate | Reuse the bounded 03-01/03-02 observations and one representative row per outcome; do not add repository-wide scanning or fault cross-products. |
| T-03-14 | Spoofing/Repudiation | high | optional real-tool smoke → CI/evidence claims | mitigate | Keep a separate opt-in status artifact, reuse the Taskfile isolation test, do not invoke smoke during this plan or `task check`, and never report an unexecuted smoke as verified. |
| T-03-SC | Tampering | low | package supply chain | accept | No package install or dependency change occurs; only existing project/test dependencies and standard-library serialization/hashing are used. |
