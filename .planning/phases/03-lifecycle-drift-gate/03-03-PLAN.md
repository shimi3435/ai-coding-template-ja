## Trust Boundaries

| Boundary | Description |
|---|---|
| source-commit Git blobs and canonical/tracked bytes → evidence producer | Repository inputs are security-relevant; pinned bytes must be bounded, root-bound, claim-validated, and neither substituted nor mutated. |
| public lifecycle decision → tracked evidence | A serializer could omit blocking fields, relabel unknown as clean, or produce non-repeatable reviewer output. |

| optional external tools → normal CI/evidence claims | Tool availability and outputs are environment-dependent and must not become an implicit green prerequisite or unverified lifecycle proof. |
