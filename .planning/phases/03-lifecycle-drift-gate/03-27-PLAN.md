The confirmed TDD seams are public `preview_manifest_migration` followed by public `apply_manifest_migration`. The input contract is `SourceIdentityState | None`; `validate_source_identity_state` and `reconcile_source_items` already accept supported `SourceIdentityState` subclasses and return the exact valid object.

The no-collision counterexample uses `FalseySourceIdentityState(next_requirement_id=1, next_scenario_id=1, active=(), tombstones=())`. Under the old implementation reconciliation succeeds, but `_preview_has_valid_shape` rejects the resulting preview because it requires the exact base runtime type, so public preview returns PERSISTENCE / `migration-preview-invalid` / UNKNOWN.

Use the canonical validator result rather than a bare `isinstance` relaxation. Import `validate_source_identity_state`, remove only the conflicting exact-type predicate, and require validator `Success` inside `_preview_has_valid_shape` after exact outer-preview and bounded scalar/container admission but before `_preview_is_consistent`, serialization, or identity hashing. This preserves the established validation ordering, accepts the same supported subclasses as reconciliation, rejects malformed nested state through one authority, and keeps the public preview-invalid taxonomy.

`serialize_manifest_v2` intentionally reparses and compares the parsed exact-base manifest with its input. Passing a manifest whose `source_items` remains a subclass therefore fails dataclass runtime-class equality even after shape admission succeeds. Keep `preview.previous_source_items` as the exact caller object and keep all source-context/preview identity fields derived from its validated fields, but inside `_preview_is_consistent` construct an exact-base `SourceIdentityState` with the same counters, active tuple, and tombstone tuple solely for the `previous_validation` serialization round-trip. Do not change `manifest_v2.py`, its parser, serializer, schema, or equality contract, and do not replace the preview field or candidate state with that projection.
