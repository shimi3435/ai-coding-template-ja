## Trust Boundaries

| Boundary | Description |
|---|---|
| repository bytes → canonical observer | Untrusted paths and bytes can be missing, malformed, aliased, replaced, or oversized and must not yield partial green. |
| tasks.md bytes → checkbox normalizer/progress split | Over-broad normalization can conceal specification drift as ordinary progress. |
| observation values → classifier | Incomplete, duplicate, or ambiguous evidence can produce a false clean decision if cardinality and ordering are not exact. |

## STRIDE Threat Register

| Threat ID | Category | Severity | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-03-01 | Spoofing/Tampering | high | canonical path and artifact observation | mitigate | Reuse canonical path validation, symlink/alias rejection, exact artifact cardinality, same-byte hash/content evidence, and whole-operation failure. |
| T-03-02 | Tampering/Elevation of Privilege | high | checkbox specification normalizer | mitigate | Replace only exact line-start checkbox tokens, preserve every other byte, prove non-checkbox edits drift with fixed literals, and confine properties to this seam. |
| T-03-03 | Repudiation | medium | drift decision evidence | mitigate | Frozen result values, stable issue codes, deterministic unique sorted affected paths, and explicit progress-only evidence. |
| T-03-04 | Denial of Service | high | repository and normalization inputs | mitigate | Existing file/count/aggregate limit+1 reads plus bounded task count; truncation and parse failure become `unknown` with no partial snapshot. |
