# 用語集と設計判断

文書種別: 参照先リファレンス。

この repository は single-context とし、用語の正本を root の [GLOSSARY.md](../../GLOSSARY.md) とする。
domain-modeling、grill-with-docs、診断、テスト設計で用語を参照・更新するときは、このファイルを使う。
同義語の選択は `_Avoid_` に従う。別の用語集を旧名 CONTEXT.md で作らない。

研究・製品の設計判断は `docs/adr/` を使う。既存の判断を参照し、新しいADRは必要な判断が生じた時だけ作る。
用語集とADRは実装仕様や作業進捗の代用にしない。仕様・進捗の正本は
[workflow](workflow.md) が定める OpenSpec artifacts と `tasks.md` である。

過去記録に残る CONTEXT.md は当時の名称であり、現在の用語集を二重管理する指示ではない。
