# spec-holes（仕様の穴の機械的列挙と検証接続）

仕様の穴（未定義の振る舞い）を注意力に依存せず**固定タクソノミーで機械的に列挙**し、
列挙した穴を**機械が反証できる形（テスト）まで運ぶ**。grill 系 skill が「ユーザに聞く」
装置であるのに対し、本 skill は「聞かれなかったこと」を残さないための装置。

2 フェーズ型で、強制度は非対称:

- **フェーズ 1（仕様時）は無条件**。OpenSpec proposal / spec delta を確定する前に必ず実行する。
- **フェーズ 2（実装時）は努力目標**。可能ならテストに落とし、落とせないものは理由を明記する。

## フェーズ 1: 仕様時の列挙（無条件）

OpenSpec proposal / spec delta の**各要件**に対して、下記タクソノミーを**順に全項目**当てる。
各項目について「この入力・状態のとき仕様上どうなるか」が未定義かどうかを判断し、
**該当 / 非該当を明示する**。「該当しない」と判断した項目はスキップしてよいが、
判断そのものは省略しない（黙殺しない）。

### タクソノミー（12 分類）

1. **空・ゼロ長・None**: 空リスト・空文字列・空データフレーム・None / 欠損値。
2. **境界値**: 最小・最大・off-by-one（0 / 1 / N-1 / N / N+1）。
3. **重複・衝突**: 重複キー・同名エントリ・一意性制約の衝突。
4. **順序**: 未ソート入力・逆順・ソートの安定性・順序依存の暗黙前提。
5. **型・形式不正**: 想定外の型・スキーマ違反・パース不能な形式。
6. **エラー経路**: 例外発生時・部分失敗（途中まで成功）・リトライ時の振る舞い。
7. **冪等性・再実行**: 同じ操作を 2 回実行したとき・中断からの再開。
8. **時刻・タイムゾーン**: TZ 依存・夏時間・時刻の逆行・日付境界。
9. **文字列**: Unicode（結合文字・絵文字）・空白のみ・エンコーディング差異。
10. **数値**: NaN・inf・負数・ゼロ除算・浮動小数点精度。
11. **巨大入力・リソース枯渇**: 想定を超えるサイズ・メモリ / ディスク / タイムアウト。
12. **状態遷移の未定義パス**: 定義済み遷移以外の操作・不正な状態からの呼び出し。

研究コードの常態を意識し、**数値系（NaN / inf / 精度）・乱数シード・空データフレーム**は
非該当にする前に一度立ち止まって判断する。

### 穴の潰し方（3 択・必ずいずれかで潰す）

列挙した各穴は、次のいずれかで**必ず**潰す。暗黙に落とすことは許されない。

1. **仕様に振る舞いを明記する**: 正常系 / エラー系のシナリオを proposal / spec delta に追加する。
2. **スコープ外と仕様に明記する**: 対応しないことを明文化する（暗黙に落とさない）。
3. **ユーザに確認する**: 判断がユーザに属するもの（トレードオフ・ドメイン判断）は
   grill 系と同じ扱いで質問し、回答を仕様に反映する。

### フェーズ 1 の出力形式

要件ごとに、タクソノミー各項目の判断を表で出す:

```markdown
| # | 分類 | 判断 | 穴の内容 | 潰し方（1: 明記 / 2: スコープ外 / 3: ユーザ確認） |
| --- | --- | --- | --- | --- |
| 1 | 空・ゼロ長・None | 該当 | 空リスト入力時の戻り値が未定義 | 1: 空リストは空リストを返すと明記 |
| 2 | 境界値 | 非該当 | —（入力に序数的な境界がない） | — |
```

## フェーズ 2: 実装時のテスト化（努力目標）

フェーズ 1 で仕様に埋めた各穴を「例示テスト or Hypothesis property」に対応付ける
**対応表**を作り、可能ならテストに落とす。

### property 化の向き不向き

- **向く対象（Hypothesis を使う）**: 純関数・パーサ / シリアライザ・データ変換。
  特に「往復で元に戻る（roundtrip）」「順序に依らない」「冪等」などの不変条件が
  言えるもの。
- **向かない対象**: I/O glue・実験スクリプト・外部依存が絡むもの。これらは
  **例示テストに落とす**か、verify-change と同じ規律で**「未検証」と理由を明記**する。

### フェーズ 2 の出力形式

```markdown
| 穴 | 検証形態 | テスト（予定含む） | 備考 |
| --- | --- | --- | --- |
| 空リスト入力 | 例示テスト | tests/test_foo.py::test_empty_list | |
| roundtrip 不変 | Hypothesis property | tests/test_foo.py::test_roundtrip | st.lists(st.integers()) |
| 外部 API タイムアウト | 未検証 | — | 外部依存のためモック困難。理由を PR に明記 |
```

対応表の漏れ（列挙した穴にテストも未検証記載もない状態）は self-review が照合して
検出する。フェーズ 1 の穴リストを残しておき、self-review 時に突き合わせられるようにする。
